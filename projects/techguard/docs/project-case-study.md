# Project Case Study

## Problem

Technology records, access decisions, operational risks, evidence, and tickets are often kept in separate spreadsheets or conversations. That makes follow-up difficult and weakens audit readiness.

## Solution

TechGuard brings the operating model into one workspace. A governance lead can see the control posture, open risks, access reviews, evidence gaps, assets, and IT service work from one dashboard.

## Intended users

- IT Governance Lead: owns the workspace and follows up on gaps.
- Control Owner: provides evidence and completes assigned reviews.
- Auditor: reads the evidence trail and identifies exceptions.
- IT Service Desk: manages tickets, ownership, priority, and SLA status.

## What the project demonstrates

- Requirements thinking and information architecture.
- Practical security and governance workflows.
- Role-based operating model.
- Risk scoring and prioritization.
- Evidence-based assurance.
- Connection between IT operations and governance.

## Next release

The next release should add authentication, a persistent database, an approval workflow, CSV import/export, configurable review cadence, and a control mapping layer that can be tailored to the selected organization or framework.
